# «Белка Соломон»

Игра в жанре **Vampire Survivors**: Соломон-белка отбивается от бесконечных
волн школьной атрибутики — учебников, указок, мела, ластиков и дневников.
Оружие Соломона — тоже канцелярия: карандаши, ластики, линейки, тетради.

## Играть

**Онлайн:** <https://littlesava01-rgb.github.io/solomon-survivors/>

**Локально:**

```bash
npm install
npm run dev      # http://127.0.0.1:5173
```

На телефоне игра ставится как приложение (PWA): «Установить приложение» в
Chrome на Android, либо «Поделиться → На экран “Домой”» на iOS.

## Как играть

Соломон бегает по кругу и **не бьёт сам** — оружие работает автоматически.
Ваша задача — не стоять на месте: собирайте зачётные звёзды, подбирайте
карточки при повышении уровня и не дайте толпе задушить белку.

| | |
|---|---|
| **WASD / стрелки** | движение |
| **Экранный джойстик** | движение на телефоне (левая нижняя четверть экрана) |
| **1 / 2 / 3** | выбор карточки апгрейда |
| **ESC** | выход в меню |

**Враги — это учебная атрибутика:** тетрадь, мел, указка, карандаш, линейка,
ластик, учебник, дневник, краска, рюкзак. Позже приходят боссы: Контрольная,
Дневник с двойками и Диплом.

**Оружие — тоже канцелярия:** карандаш (бросается), ластик (кружит вокруг),
указка (удар по дуге), линейка (черта через всех), тетрадь (клякса на земле),
краска (залп с лужей), формула (самонаводящиеся снаряды).

## Стек

Phaser 3 · TypeScript · Vite · vite-plugin-pwa · Vitest · GitHub Actions → GitHub Pages

## Структура

```
src/
  main.ts              — точка входа, конфиг Phaser
  config/              — баланс и константы
  data/                — таблицы врагов, оружия, апгрейдов, волн
  entities/            — Player, Enemy, Projectile, XPOrb, Pickup
  managers/            — Spawn, Weapon, Upgrade, Collision
  systems/             — ObjectPool, SpatialGrid, HUD, Input, Audio, Save
  scenes/              — Boot, Menu, Game, LevelUp, Pause, GameOver
  assets/              — спрайты, иконки, шрифты
docs/                  — дизайн, аудит ресурсов, публикация
scripts/               — подготовка спрайтов, симуляция баланса
```

## Статус

Игра уже играбельная: меню, арена, движение Соломона, 10 типов врагов и
3 босса, 7 видов оружия с пятью уровнями, 8 пассивок, level-up с тремя
карточками, зачётные звёзды и экран поражения с разбором забега.

Не доделано (этап 4–5 плана): тайлы биомов вместо сетки-заглушки, стрельба
врагами, мета-игра с зачёткой между забегами, звук.
