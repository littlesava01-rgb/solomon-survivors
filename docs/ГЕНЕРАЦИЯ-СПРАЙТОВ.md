# Генерация спрайтов

Спрайты рисуются моделью **gpt-image-2.6-sunburst** (через `image_generate`
или прямым запросом к API) и лежат в `art/`:

```
art/
  sheets/     — исходные сетки 1536x1024 (по одной на 6 спрайтов)
  sprites/    — готовые PNG, нарезанные и с прозрачным фоном
```

---

## 1. Главный принцип: один промт → шесть спрайтов

Генерация по одной иконке — дорого и долго. Вместо этого модель рисует
**сетку 3×2 на плоском кремовом фоне** (1536×1024 → ячейки 512×512):
шесть спрайтов за один запрос, ~30–40 секунд.

Один забег (14 заданий) — около 7 минут.

```bash
cd scripts
python3 gen_sheets.py all      # сетки -> art/sheets/
python3 cut_sprites.py         # нарезка -> art/sprites/
```

`gen_sheets.py` пропускает уже существующие файлы — можно перезапускать
безопасно, докачаются только недостающие.

---

## 2. Почему сетка, а не по одной картинке

На **неполной** сетке (2 или 4 ячейки вместо 6) модель «разъезжается»:
рисует композицию 2×2 вместо сетки, и нарезка по 3×2 ломается. Поэтому
остаток списка (<6 штук) генерируется **одиночными кадрами** 1024×1024
с промтом `LAYOUT: exactly ONE single object...`.

В проекте это правило даёт:

| Группа | Спрайтов | Как генерируются |
|---|---|---|
| Враги | 10 | 1 сетка (6) + 4 одиночных |
| Снаряды и лут | 2 | 2 одиночных |
| Оружие | 6 | 1 сетка |
| Эффекты | 3 | 3 одиночных |
| Боссы | 3 | 3 одиночных (крупные — нужна детализация) |

---

## 3. Промт

Стиль задан в `scripts/gen_sheets.py` (константа `STYLE`). Ключевые части:

- **Палитра** — совпадает со 110 готовыми иконками: крем `#FFF7ED`,
  оранжевый `#F97316`, тень `#7C2D12`, пергамент `#FDE68A`,
  коричневый `#92400E`, бирюза `#0F766E`, синий `#1E3A5F`,
  контур `#1E293B`.
- **Вид** — «top-down GAME SPRITE sheet, three-quarter top-down angle like
  an arcade survival game, NOT an isometric icon and NOT a side view».
  Это критично: по виду сверху считаются коллизии на арене.
- **Раскладка** — «a clean 3x2 grid of 6 separate game sprites, one sprite
  per cell, equal square cells, a clear empty cream gap...».
- **Запрет сцен** — «EVERY cell of the grid must hold exactly one of the
  listed objects. Do not merge objects into a scene, do not add scenery...».
  Без этой строки модель рисует виды города, а не набор спрайтов.
- **Запрет текста** — «No text, no letters, no numbers anywhere, including
  on covers, labels and pages. Blank covers only.» Иначе на обложке учебника
  появляется «Математика 5 класс».

## 4. Нарезка и прозрачный фон

`scripts/cut_sprites.py`:

1. Режет сетку 3×2 на ячейки 512×512 (или 1×1 для одиночных кадров).
2. **Удаляет фон связностью с краем**, а не порогом по всему кадру.
   Порог «цвет ≈ #FFF7ED» съел бы белые детали внутри спрайта — мел,
   бумагу, снег. Связность с краем выедает только фон.
3. Обрезает по содержимому, вписывает в целевой размер (24…224 px)
   с ресайзом **LANCZOS** и квантованием к палитре стилевого якоря.
   NEAREST на таком масштабе выбрасывает целые блоки пикселей,
   а ресайз без квантования даёт кашу из полупрозрачных краёв.

Размеры спрайтов и их id — в `scripts/sprites_catalog.py`. Этот же файл
задаёт и промт, и раскладку нарезки, поэтому порядок не может разойтись.

## 5. Проверка

```bash
# контактный лист всех спрайтов
python3 - <<'PY'
from PIL import Image
import glob, os
files = sorted(glob.glob("art/sprites/*.png"))
CELL, COLS = 72, 8
rows = (len(files) + COLS - 1) // COLS
sheet = Image.new("RGBA", (COLS*(CELL+8)+8, rows*(CELL+8)+8), (28,32,40,255))
for i, f in enumerate(files):
    im = Image.open(f).convert("RGBA")
    im.thumbnail((CELL, CELL), Image.Resampling.NEAREST)
    x = 8 + (i%COLS)*(CELL+8) + (CELL-im.size[0])//2
    y = 8 + (i//COLS)*(CELL+8) + (CELL-im.size[1])//2
    sheet.alpha_composite(im, (x, y))
sheet.convert("RGB").save("art/preview_all.png")
print("saved", len(files))
PY
```

Что смотреть в листе:

- **Заполненность** — доля непрозрачных пикселей. Ниже ~8 % скорее всего
  «съедено» фоном или пусто.
- **Силуэт** — должен читаться в 32 px.
- **Содержание** — попросить vision-модель назвать предмет в каждой ячейке
  и сравнить с ожидаемым списком: генератор подменяет предметы
  («метла» вместо «швабра»).

## 6. Ограничения API

- `gpt-image-2.6-sunburst` **не входит в каталог плагина openai**,
  поэтому `image_generate` уходит в него passthrough **без параметра
  `quality`**. Чтобы рисовать с `quality=low` (в 3–4 раза дешевле),
  нужен прямой POST на `/v1/images/generations` — его и делает
  `scripts/gen_api.py`.
- **429 от провайдера** — норма при трёх воркерах. В `gen_api.py` зашит
  экспоненциальный backoff (15 с × попытка, потолок 180 с, 6–7 ретраев);
  без него падает вся пачка.
- **Прозрачный фон API не выдаёт** — рисуем на кремовом и вырезаем сами.

---

## 7. Добавить новые спрайты

1. Дописать запись в `scripts/sprites_catalog.py` (id, размер, описание).
2. `python3 scripts/gen_sheets.py <group>` — сгенерировать недостающие.
3. `python3 scripts/cut_sprites.py` — нарезать.
4. Добавить импорт в `src/assets/sprites.ts` и ключ в `SPRITES`.
5. Проверить контактным листом.
